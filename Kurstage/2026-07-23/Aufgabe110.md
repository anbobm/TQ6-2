## Aufgabe 110
Schreibe eine HTML-Seite mit einem Anmeldeformular für ein Freizeitcamp. Es soll folgendes abgefragt werden:

- Vorname
- Nachname
- Email-Adresse
- Passwort
- Geburtsdatum
- Telefonnummer
- Lieblingsfarbe
- Tischtennis-Skill (1 bis 10) input range
- Lieblingsaktivität (genau eine auswählen aus einer vorgegebenen Liste)
- Mahlzeiten: Frühstück, Mittagessen, Abendessen (frei kombinierbar)
Nimm vorerst ein p-Element pro Formularfeld, damit nicht alle Felder in einer Zeile dargestellt werden.
