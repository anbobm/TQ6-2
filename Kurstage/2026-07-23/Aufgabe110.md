# Aufgabe 110

Schreibe eine HTML-Seite mit einem [Anmeldeformular](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_forms) für ein Freizeitcamp. Es soll folgendes abgefragt werden:

* Vorname
* Nachname
* Email-Adresse
* Passwort
* Geburtsdatum
* Telefonnummer
* Lieblingsfarbe
* Tischtennis-Skill (1 bis 10) [input range](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/range)
* Lieblingsaktivität (genau eine auswählen aus einer vorgegebenen Liste)
* Mahlzeiten: Frühstück, Mittagessen, Abendessen (frei kombinierbar)

Nimm vorerst ein `p`-Element pro Formularfeld, damit nicht alle Felder in einer Zeile dargestellt werden.
